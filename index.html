1 Engineering focus & background

Rabbany's technical practice combines low-level Windows systems programming with modern, design-forward web engineering. On the systems side, their focus centers on Win32 API internals, display affinity masking, assembly inspection, and reverse engineering automation.

In parallel, Rabbany develops cloud-native web architectures utilizing TypeScript, React, Next.js, and Python. Their frontend work prioritizes bespoke typography, fluid aerodynamics in HTML5 Canvas animations, and accessible component architectures.

2 Core & focused projects

Rabbany's active, maintained portfolio focuses on the following key projects:

2.1 AuthLX Platform

AuthLX is an authentication, licensing, and user management platform engineered by Rabbany.[2] It provides end-to-end access verification with client SDKs published across official registries (NuGet and PyPI) in Python, C++, C#, and Java.

The ecosystem incorporates a dedicated Discord bot application serving over 10,000 users, allowing server administrators to generate, revoke, and bind software licenses directly through chat interfaces.

Stack: Next.js, TypeScript, Python, C++, PostgreSQL, Discord API • authlx.com

2.2 WindowCaptureHider

A high-performance Windows dynamic link library (DLL) that shields top-level application windows from screen capture and recording software, such as OBS Studio and the Windows Snipping Tool.[3]

The utility leverages the native SetWindowDisplayAffinity API, offering developers and security-conscious users seamless privacy against unauthorized screen scraping and streaming leaks.

Stack: C++, Win32 API • 24 stars, 5 forks • AGPL-3.0

2.3 DnSpyMCP (.NET Reverse Engineering)

An extensible Model Context Protocol (MCP) server designed to connect modern LLM coding agents directly to .NET reverse engineering and disassembly pipelines.[4]

DnSpyMCP exposes 31 structured tools enabling automated IL2CPP dump analysis, assembly cross-referencing, metadata extraction, and binary patch synthesis.

Stack: C#, .NET, Model Context Protocol (MCP) • 8 stars, 3 forks • MIT

2.4 DiscordServerClonner

A Python utility engineered for server structure preservation, emoji and sticker archiving, channel taxonomy backup, and token validation without requiring elevated administrative privileges on source servers.[5]

Stack: Python, Asynchronous I/O, REST APIs • 1 star, 7 forks • MIT

2.5 VideoCaptionBurner

An automated media utility wrapping FFmpeg to render, synchronize, and hard-code styled captions into video files with sub-frame accuracy and precise typographical control.[6]

Stack: Python, FFmpeg • MIT
