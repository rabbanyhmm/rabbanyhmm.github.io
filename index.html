Rabbany — known on GitHub as rabbanyhmm, and formerly as myexistences — is a creative frontend engineer and technical animator whose public work spans reverse engineering, Windows and Android systems programming, and browser-based motion design.[1] Across seventeen public repositories and a larger body of private work, they have built tools for .NET and IL2Cpp analysis, screen-capture privacy, Discord automation, and video processing, alongside product-facing interface components and animation systems. They also build and maintain AuthLX, an authentication and licensing platform, and contribute to the open-source is-a-dev/register subdomain registry.

1 Career

Rabbany's early public work centered on reverse engineering and Windows systems: IL2Cpp dump analysis, PE inspection, DLL injection, and Dear ImGui overlay tools, alongside security research spanning malware analysis, vault encryption, and anti-cheat systems. This work was published under the handle myexistences, before a rebrand carried out in mid-2026 consolidated their output under the name Rabbany — including a redesigned GitHub profile with curated featured projects and a more deliberate visual identity.

Alongside this systems and security work, Rabbany builds full-stack web products in TypeScript, Next.js, Python, and PHP, and maintains a parallel practice in frontend engineering and motion design: animated interface components, editorial-style infographics, and design-forward tooling for both personal and client projects.

2 Notable projects

Selected projects from Rabbany's public and ongoing work:

2.1 Open-source tools

  • WindowCaptureHider — Rabbany's most-starred public repository: a lightweight Windows DLL that hides top-level windows from screen-capture utilities such as OBS and the Snipping Tool, using the SetWindowDisplayAffinity API. C++, AGPL-3.0.[2] (24 stars, 5 forks)
  • DnSpyMCP — an MCP (Model Context Protocol) server for .NET reverse engineering, exposing 31 tools for IL2Cpp dump analysis, assembly cross-referencing, and network-traffic patching. C#, MIT.[3] (8 stars, 3 forks)
  • DiscordServerClonner — a Python tool for duplicating Discord servers, including their emoji and sticker sets, and validating tokens, without requiring administrator permissions on the source server. MIT.[4] (1 star, 7 forks)
  • VideoCaptionBurner — an ffmpeg-based Python tool for generating, styling, and burning subtitles into video, with fine control over timing and layout. MIT.[5] (2 stars)
  • SignatureClone — a Python research tool for cloning digital signatures between Windows executables, built for PE-format analysis and educational testing.[6] (5 stars)

2.2 AuthLX

AuthLX is an authentication and licensing platform Rabbany builds and maintains, providing SDKs for Python, C++, C#, and Java — with several more languages in progress — plus a Discord bot for managing licenses and users directly from a server.[7] The package is published on both NuGet and PyPI, under the handles rabbanyhmm and myexistences, with a dedicated Slack workspace for the team behind it.

2.3 Trusty and Authera

Trusty and Authera are backend and database projects Rabbany hosts on Supabase.

2.4 AuthLX

AuthLX is a Discord application built and operated by Rabbany that has grown past 10,000 users, with ongoing work focused on scaling its infrastructure to support continued growth.

2.5 is-a-dev/register

Rabbany is an active contributor and pull-request manager for is-a-dev/register, the open-source repository behind is-a.dev — a free service that lets developers claim a personal *.is-a.dev subdomain by opening a pull request.[8]

3 Creative and frontend engineering

Rabbany's frontend work leans toward motion and craft as much as engineering. Recent projects include a cherry-blossom petal-fall component — a production React and TypeScript canvas animation simulating falling petals through a seven-stage aerodynamic physics cycle, with object pooling for performance and a reduced-motion mode for accessibility. A parallel editorial version paired the same animation with Cormorant Garamond and Inter typography across a twelve-column grid.

Other recent work includes a single-file color-picker component supporting HSV, RGB, HEX, and HSL input, with a dark glassmorphic theme, spring-based animations, and native EyeDropper API integration for sampling colors directly from the screen; and an Android system that lets an AI agent drive on-device memory-analysis tooling over a local, secured IPC channel, built as a Kotlin foreground service with task scheduling, automatic crash recovery, and a three-layer security model.

Rabbany's personal visual identity — used across their GitHub profile and other projects — favors cherry blossom and sakura motifs, set in a cream, rose, and burgundy palette.
